# Avel (Easzy)

Freelance developer based in France. I build web applications, SaaS platforms, Shopify apps and automation tools, from the first prototype to production.

I work in French and English.

## What I build

- Web applications and SaaS platforms (multi-tenant, payments, back offices)
- Shopify apps and themes, WooCommerce plugins, third-party API integrations
- Backends and APIs, data pipelines, automation of repetitive business tasks
- Interactive 3D and real-time projects (WebGL, Godot, game and simulation prototypes)

Stack: TypeScript, React, Node.js (Fastify, NestJS), Python (FastAPI), PostgreSQL, Redis, Docker, Railway, Shopify, Godot.
